# Сервис модерации объявлений

HTTP API на FastAPI, которое по данным объявления определяет, есть ли в нем нарушение.

## Технологии

- Python 3.11+
- FastAPI
- Pydantic
- pytest

## Установка

```
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Команда активации приведена для PowerShell. На Linux и macOS: `source .venv/bin/activate`.

## Запуск

```
fastapi dev
```

Документация Swagger UI: http://127.0.0.1:8000/docs

## Тесты

```
python -m pytest
```

## Логика предсказания

`POST /predict` возвращает одно булево значение:

- `true` - нарушение найдено;
- `false` - нарушения нет.

Правила:

1. Объявление подтвержденного продавца всегда без нарушений.
2. Объявление неподтвержденного продавца без нарушений, если в нем есть хотя бы одно изображение.
3. Объявление неподтвержденного продавца без изображений считается нарушением.

Все поля обязательные, типы проверяются строго: например, строка `"1"` не принимается вместо числа, а `1` или `"true"` вместо булева значения. Дополнительно `seller_id` и `item_id` должны быть больше 0, `name` не может быть пустым, `images_qty` не может быть отрицательным.

## Пример запроса

```json
{
  "seller_id": 1,
  "is_verified_seller": false,
  "item_id": 100,
  "name": "Велосипед",
  "description": "Горный велосипед в хорошем состоянии",
  "category": 3,
  "images_qty": 0
}
```

Ответ `200 OK`:

```json
true
```

## Коды ответа

- `200` - предсказание выполнено, в теле `true` или `false`;
- `400` - некорректные входные данные, в теле `detail` со списком ошибок;
- `500` - внутренняя ошибка сервера, в теле `{"detail": "Internal Server Error"}`.

## Структура

```
main.py                     приложение, роутер, обработчики ошибок
routers/moderation.py       обработчик POST /predict
services/moderation.py      правила модерации
repositories/moderation.py  параметры правил (хранятся в памяти)
schemas/advertisement.py    Pydantic-модель объявления
tests/                      тесты
```
